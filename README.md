# Elytra Chestplates
Combine your Elytra and chestplate! 

This is an experimental resource pack and datapack combo for Minecraft Java that allows you to create an item that is an Elytra and chestplate in one item.

> [!WARNING]
> This is a highly experimental resource/datapack. I do not recommend using this in a serious survival world as there is no way to seperate the Elytra and chestplate in the current version.

## Downloads
Downloads can be found here.

## How to Install
1. Download both the datapack and resource pack
2. Place the file titled `§lElytra Chestplates§r§8v1.0a.zip` into your resource pack directory; you can get there by going into Options --> Resource Packs --> Open Pack Folder
3. Place the file titled `ElytraChestplates_Data_v1.0a` into your world's datapack folder; you can get there by going into Edit World from the main menu --> Open World Folder

## Obtaining the Items
As this is a resource/datapack only, the items will not appear in the creative menu. You can obtain the items by either using commands or by crafting them.

### Crafting
Combine any chestplate and an elytra in the crafting grid.

### Using Commands
Use the following commands to obtain each combined chestplate:

**Leather Tunic**
/give @p leather_chestplate[item_model="elytra_chestplates:leather_tunic_elytra",lore=[{"color":"gray","shadow_color":11184810,"text":"Combined with Elytra"}],equippable={slot:"chest",equip_sound:"item.armor.equip_leather",asset_id:"elytra_chestplates:leather_tunic_elytra"},rarity="epic",glider={}] 1
